GitHub

GitHub es una pagina web que funciona com un repositorio, aparte de como un sistema de control de versiones, para los trabajos que realice cualquier persona, ya sea un producto de una empresa, con datos privados, o una persona en su tiempo libre, esta enfocada a el codigo abierto o/y libre, eos implica que la mayor parte de los presnetado en la plataforma es de uso gratuito, al menos a nivel perosnal, pues otros pueden requerir de una licencia especial para su venta
