Documentacion

Aqui encontraremos distintas fuentes que pueden ayudarnos a resolver los problemas en la creacion de nuestra pagina web, apuntes y "chuletas" que nos permitan obtener una base

GitHub Pages

La herramienta de github places nos permite alojar nuestros archivos de una pagina web (JavaScripts, CSSs, HTMLs) para su despliegue en la red mediante el servidor de GitHub

Enium

Enium es una pagina que nos enseñara las bases para trabajar en el diseño web, creando paginas, estructuras basicas, teoria de colores, como trabajar con colores, procesos creativos para la creacion de paginas web, desde un simple boceto hasta su prototipo y futuro despliegue; Tambien nos enseñara el como interacturas con dichas paginas, ademas de que pone a nuestra disposicion cursos con los que extender nuestro trabajo
